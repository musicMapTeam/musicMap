# 回声场刊 · 影片视觉规范

## Style Prompt

以中文动态排版为主的当代音乐节场刊：文字有节奏，界面截图保持完整、可辨认。墨黑画布承托海沫绿与珊瑚色的短促交接，纸白只用于票根与重点文字。辅助同心线象征不同视角交汇，不声称是音频频谱。影片是实际页面截图组成的功能流程展示，不伪装为连续录屏。

## Colors

| 色值 | 角色 |
| --- | --- |
| `#0C1016` | 主画布、深色文字 |
| `#F2EFE7` | 纸白、主要文字 |
| `#70DDCF` | 音乐探索、本人视角 |
| `#FF7E59` | 现场相遇、另一视角 |
| `#B5C4C1` | 深色背景上的次级说明 |

## Typography

- 中文采用本机 Microsoft YaHei；大标题 84–136 px、粗体，正文 30–38 px、常规体。
- 标签与时间码采用 Consolas，中文回退 Microsoft YaHei；数据标签不低于 20 px。
- 保留完整中文字形，以整行位移表达节奏；操作与能力边界不做扭曲或字母拆分。
- 截图中的文字属于真实 UI，关键操作另配大号中文字幕解释。

## Motion

- 1920 × 1080，30 fps，94 秒，无旁白、无配乐。
- 页面镜头采用 0.5 秒横向推页为主，双联结果与结尾使用 0.55 秒交叠淡化。
- 每镜先出现标题，再出现截图，再出现说明；正文留足阅读时间。
- 页面截图不添加伪光标、伪点击或伪成功反馈。
- 每镜最多一个缓慢装饰运动，照片与正文不持续漂浮。

## What NOT to Do

- 不把静态截图序列写成连续录屏或真实现场拍摄。
- 不声称已上线公网、已接真实音乐库、已接真实音频或具备 AI 推荐。
- 不把本地 A/B 演示冒称为真人双端；联网房间单独介绍。
- 不使用炫光、抖动、粒子洪流与字幕难以阅读的转场。
- 不下载模型权重，不调用外部 TTS，不引入未经授权的音乐。
