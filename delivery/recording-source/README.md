## 编辑与渲染

已读旧 `video-source/DESIGN.md` 与 `cover.html`，沿用墨黑、纸白、海沫绿、珊瑚色以及微软雅黑 / Consolas。实际画面用 **FFmpeg** 剪辑并烧录 ASS 中文字幕；不重建 HyperFrames 截图影片，不增加模型或在线 TTS。封面为独立静态 HTML。

1. `edit-plan.json` 已记录每段实际 `file`、`in` / `out`、末帧 `hold`、角色标签、字幕和剪辑说明。字幕时间相对于**这一段剪后画面起点**，不是全片时间。
2. 当前 `status` 为 `ready-to-render`，所用素材须在本机可读。若换原片，先核对实际动作并调整字幕，不能沿用旧时间点宣布新画面完成。
3. 在仓库根运行：

```powershell
node delivery/recording-source/render.mjs
```

需要本机 Node、FFmpeg / ffprobe 与 Microsoft YaHei 字体，本轮已实际运行。脚本默认输出在本目录的 `rendered/`：MP4、全片 SRT 和剪辑清单；本轮完成检查后已将 MP4 复制到 `delivery/music-map-space-demo.mp4`。重渲染脚本本身不直接覆盖交付文件。

合成采用等比画面和固定外置字幕区，顶部标章节与角色，底部标演示范围；字幕不叠在关键按钮上。不同 A/B 镜头直接切换并持续标记角色，视频无旁白、无音乐、无音轨。
