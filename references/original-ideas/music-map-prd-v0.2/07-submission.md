# 参赛材料工作稿

截止：最晚 2026-10-09 提交。赛道：创新音乐产品。以下是为团队准备的工作稿，不代表已经完成提交或正式 Demo。

## 1. 作品介绍及创作思路

以下文案在 100—300 字范围内。以构思表述，待真实数据、试听与上线版本完成后核对，不把虚构原型包装为已运行的音乐服务。

> Music Map 面向关注艺人、愿意探索的年轻乐迷，回应“喜欢熟悉的歌手，却不知道如何发现相关新声音”的需求。项目拟将艺人合作与风格联系转化为可拖动、可旋转的空间关系网，让用户从自选艺人出发，沿连接自由漫游、试听代表作，并将喜欢的歌曲留在沿途发现清单中。用户也可自选起终点，沿合作关系完成不限时、不限步数的轻松挑战，回看经过的艺人与连接作品。灵感来自角色关系网和乐迷的歌手跳转游戏，希望让音乐发现更直观、更有参与感，并让每段探索都能留下可重访的记录。

## 2. 演示视频脚本：目标 2 分 40 秒

这是一份可按成品微调的录制顺序。原型排练使用虚构艺人；正式录制须换成已核验的真实数据，并如实呈现当时完成程度。

| 时间 | 屏幕操作 | 建议讲解 / 字幕 |
|---|---|---|
| 0:00—0:15 | 首页与产品名称 | “我们常常喜欢一位歌手，却不知道从哪里找到下一个喜欢的声音。Music Map 想让发现音乐变成一段能亲手探索的旅程。” |
| 0:15—0:30 | 搜索并选择起点 | “从自己熟悉的艺人出发，进入由音乐联系构成的空间关系网。” |
| 0:30—0:55 | 拖动、点邻居、连续换中心 | “拖动查看周围艺人，点一下就沿连接继续走。每条合作关系都有具体作品作为依据。” |
| 0:55—1:15 | 展开代表作、试听、留下 | “点击中心听代表作，喜欢的歌随手留下，不必打断探索。”正式版演示实际试听；如只有原型，明确讲“此处演示试听交互，暂无真实音频”。 |
| 1:15—1:30 | 切换风格模式、打开依据 | “除了合作，还可根据可解释的风格联系发现相似声音。”仅在真实版风格数据通过验证后保留本段。 |
| 1:30—1:50 | 返回一次、结束探索、展开回顾 | “走过的路线、途经艺人和主动留下的歌曲，都能回顾。返回换方向也不会丢掉已留下的喜欢。” |
| 1:50—2:20 | 设置挑战，沿一条已核验路线到终点 | “选起点和目标，看看能沿几次合作相遇。没有倒计时和步数上限，绕路也可能有惊喜。”可剪辑中间操作，不能伪造结果。 |
| 2:20—2:35 | X 步结果、连接作品、返回漫游 | “结果展示这次实际保留的路线与连接作品，也可以继续漫游。” |
| 2:35—2:40 | 产品名称与地图界面 | “Music Map，从喜欢，走向未知。” |

录制检查：总时长 ≤3 分钟；文件大小在 500M 以内；语音讲解或字幕清晰；无水印、杂音；作品原创合规。避免在画面中出现账号隐私、调试工具或未清理的通知。
