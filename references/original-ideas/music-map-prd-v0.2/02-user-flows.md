# 用户流程图

版本：2026-09-26。依据：[PRD v0.2](01-PRD.md)。图内都是产品行为约定；原型的虚构数据不影响流程理解。

![流程总览](../assets/user-flows.svg)

## 1. 自由漫游：从进入到结束

```mermaid
flowchart TD
  A[进入 Music Map] --> B[搜索起点 / 选择已收录艺人]
  B --> C{搜索有结果？}
  C -- 否 --> D[说明当前收录范围 / 提供示例起点]
  D --> B
  C -- 是 --> E[建立本次漫游 / 合作模式]
  E --> F[空间关系网 / 中心锚点]
  F --> G{用户操作}
  G -- 拖动 --> H[旋转视野 / 锚点与路线不变]
  H --> F
  G -- 点周围艺人 --> I[连续移动到中心 / 记录关系段]
  I --> F
  G -- 点中心头像 --> J[展开代表作 / 再点收起]
  J --> K{试听资源可用？}
  K -- 是 --> L[用户主动播放 / 单曲试听]
  K -- 否 --> M[显示暂无试听 / 仍可留下文字记录]
  L --> N[可主动留下歌曲]
  M --> N
  N --> F
  G -- 切换关系模式 --> O[保留当前锚点 / 更新邻居 / 不新增移动]
  O --> F
  G -- 查看连接依据 --> P[展示合作作品或风格依据]
  P --> F
  G -- 结束探索 --> Q[暂停音频 / 保存同一记录 / 打开回顾]
  Q --> R[留下的歌曲优先 / 路线和艺人可展开]
```

拖动手势优先于点击；移动超过阈值不触发头像。地图中所有合法邻居都必须有可访问入口，不能只展示视觉上好排布的一部分。

## 2. 本次发现、历史和再次出发

```mermaid
flowchart TD
  A[漫游 / 试听 / 查看合作作品] --> B{主动点击留下？}
  B -- 否 --> C[不增加歌曲清单]
  B -- 是 --> D[按曲目标识及版本去重 / 更新数量]
  D --> E[本次发现面板]
  E --> F{下一步}
  F -- 关闭 --> G[恢复原锚点、模式和视角]
  F -- 移除 --> H[移除歌曲 / 可撤销 / 路线依据仍保留]
  F -- 结束探索 --> I[保存结束状态 / 展示回顾]
  I --> J[我的发现 / 当前浏览器本地记录]
  J --> K{打开记录后}
  K -- 继续本次 --> L[恢复原会话 / 沿用原清单和路线]
  K -- 从某艺人再出发 --> M[新建会话 / 新清单为空 / 保留旧记录]
  K -- 删除 --> N[确认具体记录 / 删除该条]
  L --> A
  M --> A
```

“结束”是同一记录的状态变化，反复结束不重复创建历史。没有留下歌曲也能结束。浏览过的艺人不等同于“用户从未听过的艺人”。

## 3. 回退如何影响路线

```mermaid
flowchart LR
  A[林间 A] -->|合作移动| B[乔屿 B]
  B -->|合作移动| C[白川 C]
  C -. 快捷返回：导航事件 .-> B
  B -->|合作移动| D[陆遥 D]
```

| 记录 | 此例最终内容 |
|---|---|
| 当前导航路线 | A → B → D |
| 漫游完整回顾 | A → B → C；文字提示“返回 B，换个方向”；B → D |
| 若发生在挑战中 | 最终有效路线 A → B → D，共 2 步 |
| 主动留下的歌曲 | 回退不移除，仍属于该会话 |

虚线只表示导航，不是新的合作边。不能生成 C → D 的关系；若用户点相邻艺人实际沿关系返回旧节点，则属于一次新移动，应记录并计步。

## 4. 步数挑战

```mermaid
flowchart TD
  A[进入挑战 / 保存原漫游] --> B[自行选择起点和终点]
  B --> C{起终点相同？}
  C -- 是 --> D[提示换一位 / 保留选择]
  D --> B
  C -- 否 --> E{当前合作图可达？}
  E -- 否 --> F[提示当前收录关系暂未连通]
  F --> B
  E -- 是 --> G[创建本局 / 固定数据版本 / 初始 0 步]
  G --> H[沿合作关系选择相邻艺人]
  H --> I[有效路线增加一段 / 步数加 1]
  I --> J{到达终点？}
  J -- 否 --> H
  J -- 是 --> K[保存完成状态 / X 步到达]
  G --> L[快捷返回上一位 / 撤销一段 / 步数减 1]
  L --> H
  G --> M[确认回到起点 / 路线重置 / 0 步]
  M --> H
  G --> N[中途退出 / 保留未完成记录]
  K --> O{后续操作}
  O -- 再次挑战 --> B
  O -- 返回漫游 --> P[恢复原漫游；无原会话则从终点新建]
  N --> Q[恢复原漫游；无原会话则从当前艺人新建]
  N --> R[我的发现 / 继续原局]
  R --> H
```

挑战中不能切换为风格关系。看作品、模拟或真实试听、留下歌曲、拖动均不计步。歌曲不是额外计步节点，不声称最短路线。

## 5. 异常处理

| 情况 | 用户看见什么 | 可继续做什么 |
|---|---|---|
| 未收录搜索词 | 当前范围无结果 | 修改关键词或选择已有艺人 |
| 当前模式没有邻居 | 暂无收录关系 | 返回；漫游可切换模式 |
| 缺头像 | 姓名首字占位 | 照常探索 |
| 缺音频 | 暂无试听 | 仍可留下文字资料 |
| 本地保存失败 | 明确保存未成功 | 重试，当前页面保留内容 |
| 旧图谱版本无法恢复 | 原记录仍可回顾；说明无法继续原局 | 重新选择当前有效起终点，不改写旧路线 |
| 误移除歌曲 | 已移除 / 撤销 | 恢复原位置 |

最后一项图谱更新处理属于正式实现要求。原型固定一份图谱，不模拟服务器数据版本迁移，详见原型说明。
