# Music Map × Music Space

**沿音乐认识新的声音，在同一场现场遇见有共同记忆的人。**

Music Map 负责音乐关系探索；Music Space 面向音乐现场社交，以现场卡、共同音乐时刻和双方同意的交换连接同场观众。私人档案保存探索与交换结果。
