# Music Map × Music Space

**同一刻，另一面。散场以后，用另一位观众的视角，补完整你记住的那一晚。**

MVP **0.4.0** · 产品文档 **1.4** · 2026-09-27

当代音乐节排版、光学关系图、现场摄影与纸质双联票根，共同组成产品的视觉语言。视觉包装是本项目的核心成功标准。

![Music Map × Music Space 参赛封面](delivery/cover.png)

## 现在能做什么

- **音乐探索**：有来源的真实合作精选、官方作品外链、自由漫游和合作挑战；每一步留下具体的作品。虚构图谱独立保留，兼容旧探索记录。
- **本地情景演示**：制作现场卡、选择是否展示、切换Lin / 阿遥，体验申请、接受、拒绝与取消；接受后自动收好两人的双联记忆。
- **自己的音乐现场**：填写场次、可选日期／地点／歌名，上传一张自己的照片，选一个时刻和视角；默认私藏，一个人也能导出纪念卡。
- **真实同场交换**：独立匿名身份、邀请码／二维码、主动展示的卡墙；用共同瞬间和不同视角说明相遇理由。申请指向两张确定的卡，由接收者本人同意。
- **可带走的记忆**：交换后生成双联票根，可保存PNG。记录页按现场记忆 / 音乐探索浏览；后续改卡不会改写已完成的交换，各自删除自己的记录。
- **统一视觉**：Map、Space、邀请入场、制卡、交换与记录采用同一套视觉，支持手机与减少动态效果。

**真实合作有来源；听歌使用外部官方页面，本应用没有内置音频。** 本地情景和旧房间仍是虚构场次，预置图由AI生成。新房间使用参与者自行填写的活动与选择的照片，不验证到场。现有实操是内部独立会话，不代表已有外部用户或公网服务。

这轮根据比赛标准与竞品研究收紧了场景：先服务散场后的同场小圈；共同纪念是交换收益，音乐探索是可选入口。具体采用与舍弃见[竞争力复盘](references/research/2026-09-27/README.md)。

## 快速运行

需要 **Node.js 24 或更新版本**。

```sh
npm ci
npm run build
npm start
```

打开 **http://127.0.0.1:8787/**。同一个服务提供页面与 SQLite 交换接口，无需外部数据库或模型。

开发前端：`npm run dev`；真实房间开发时另开终端运行 `npm run server`。Vite 将 `/api/live` 转发到本机 `8787` 端口。

### 两种交付

| 交付 | 能力 | 条件 |
| --- | --- | --- |
| `dist/index.html` 单文件 | 完整 Map 与本地双角色情景演示 | 浏览器；可评估 WorkBuddy 等 HTML 托管 |
| Node 完整版本 | 上述功能 + 真实房间交换 | Node.js 24、同源服务与持久化磁盘；对外部署使用 HTTPS |

`npm run preview` 只预览静态页面。静态托管不能运行 SQLite 后端。`npm start` 默认仅监听本机，支持 `HOST`、`PORT`、`DATA_DIR`；完整部署和 Docker 命令见[实施规格](product/docs/03-build-guide.md)。数据库默认在 `data/music-map.sqlite`，已排除 Git，不得打进分享包。

每次推送，GitHub Actions 构建 **music-map-space-demo**（单文件）与 **music-map-space-runtime**（页面、后端、运行说明）两份产物，保留 14 天。见 [Actions](https://github.com/musicMapTeam/musicMap/actions/workflows/build.yml)。仓库同步与网站部署分别记录。

## 两分钟体验

### 一个人快速看完整流程

1. 在Map点击一位相连的艺人，看看“这一跳”带来的合作作品；进入Space后选择本地情景体验。
2. 做一张卡、留下一句话，保存后确认两张卡，再发送申请。
3. 点击“切到阿遥”，查看申请并同意。
4. 双方记忆已自动收好，可下载票根；从“我的记录”重开，或回到Space继续刚才的音乐探索。

### 两个人真实交换

1. 在完整服务页面进入“同场 → 创建 / 加入同场”。
2. 填写你们的场次，将邀请链接或二维码发给朋友；对方用自己的浏览器加入。
3. 双方各自选择照片、时刻与视角，接收方主动展示；发起方看清相遇理由，确认两张卡并申请。
4. 接收方在自己的浏览器接受，双方自动得到同一对快照。

同一台电脑可用两个浏览器或普通 / 无痕窗口。朋友的手机需要已部署的链接，或同一网络下可访问的服务地址；`127.0.0.1` 不能发给另一台设备。身份保存在浏览器，清除站点数据会失去身份访问能力，MVP 暂无账号找回。

## 完成证据与边界

0.4.0 已完成生产构建和实际页面操作：自定义场次、照片上传、私藏单卡下载、两个独立身份申请与接受、自动保存双联、实际 PNG 下载，以及真实合作专题与来源面板。查看了桌面和 390px 下的新增制卡、票根与合作列表。照片无身份请求返回 401；不扩大为完整安全审计或实体手机验收。

0.2 / 0.3 的接收者权限、快照、删除与重启等证据保留为历史记录；本轮结果单独记在[项目状态](docs/PROJECT_STATUS.md)。没有新增测试框架或全量测试套件。竞品、官方规则、开源参考及采用 / 舍弃决定见[竞争力复盘](references/research/2026-09-27/README.md)。

**仍需外部操作**：选定评审访问环境并部署、少量真实用户试用、核对报名信息并提交。官方 FAQ 对已公开上线作品有限制，发布前按[交付计划](product/docs/02-delivery-plan.md)确认定向评审方式。本轮没有购买服务器、下载模型权重或提交赛事表单。
