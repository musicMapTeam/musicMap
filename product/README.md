## 当前应用与历史参考

前端在 [`web/`](../web/)，服务在 [`server/`](../server/)。保留两种明确分开的体验：

- **本地情景演示**：同一浏览器切换两个示例角色；新交换接受后自动为双方各保存一份双联记忆，自己的卡也可单独收藏。旧版已接受但未保存的交换保留手动保存入口；相同两卡版本再次交换时打开已有双联。记录只在本机，单 HTML 可用于兼容的静态发布入口，实际发布尚未完成。
- **真实联网房间**：独立匿名身份、6 位邀请码、房内展示与撤下、指定两卡快照交换、接收者同意、双方记录自动保存、票根 PNG 导出。共享数据由同源 Node.js 24 服务和持久化 SQLite 提供，可用 Docker 部署；仅发送预置图片引用，不上传个人照片。

0.3.0 补充 Map 第一跳引导和每跳作品 / 标签反馈；Space 主入口指向真实房间，本地体验明确分开。可返回刚才的探索，也可从现场艺人另开路线；手机本地制卡优先输入并可折叠预览，记录页提供筛选与计数。联网房间区分不同空态、保存私卡后给出展示选择，离开保留重入码，票根统一使用交换完成时间。

历史上，0.2.0 已完成构建、独立浏览器会话换卡、权限与快照检查、服务重启读回及 PNG 下载查看；这些不等于 0.3.0 已验收。新版本检查由[项目状态](../docs/PROJECT_STATUS.md)逐项记录。视频与 16:9 封面已有产物，当前材料版本和镜头来源见[交付清单](../delivery/README.md)。真实音频、真实合作数据、账号找回与照片云存储尚未接入；运行方式见[根 README](../README.md)。
