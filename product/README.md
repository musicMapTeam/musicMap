## 当前应用与历史参考

前端在 [`web/`](../web/)，服务在 [`server/`](../server/)。桌面使用悬浮左导轨，手机使用底部导航。首页的「记录我的现场」和「邀请朋友」进入真实流程，有卡后显示本人记忆；没有卡时的预置图注明示例。「体验示例」单独进入本地双角色。樱花首页使用全屏小院，其他主题保留照片卡叠。

- **沿着作品认识艺人**：11 位艺人、10 首作品、10 条有来源的共同演唱关系，作品可展开逐人制作署名；独立开放曲库提供 120 首可搜索的共同署名作品。试听链接撤下，QQ 音乐同版本直达尚未核实，来源按需查看。虚构示例独立保留并兼容旧记录，真实艺人不绑定虚构活动。
- **留下音乐，回看自己的现场**：「我的记录」分为我的现场、音乐收藏、探索路线和示例。真实卡片与双联跨场次集中展示；音乐单独存于本机，不依赖探索路线。作品可「带到现场」，仅预填新场次的可编辑歌名。
- **交换自己的现场视角**：自建活动、6 位邀请码与二维码、独立匿名会话；上传压缩照片并标记舞台 / 人海 / 同伴 / 细节，默认私藏，可主动展示。对方接受指定两卡的交换后，双方各留一份当时的快照。0.4 历史实操已下载自己的单卡和双方双联 PNG。
- **保留可离线体验的情景演示**：同一浏览器切换两个示例角色，新交换接受后自动为双方保存；自己的卡可单独收藏。旧版已接受但未保存的交换可手动保存，相同两卡版本打开已有双联。记录仅在本机，单 HTML 可用于兼容的静态入口，不提供共享后端。
- **为同一段记忆选择外观**：右上角主题按钮切换默认声浪现场 `festival`、樱下放映 `sakura`、独立刊物 `zine`。樱花小院包含首页、探索、房间、工作桌、店内收藏和照片近景，手机有独立机位；真实授权卡片进入模型贴图，镜头行进与照片抬起可打断。Three 0.186.1、Sakura Crossing MIT 管线和 GSAP 3.15.0 / Flip 管理画面；切主题释放三维资源，跨路由保留。规则见[视觉主题规范](../docs/VISUAL_THEMES.md)。

真实房间与个人现场收藏需要同源 **Node.js 24 + 持久化 SQLite** 服务，可用 Docker 部署。照片通过身份和共享关系授权读取，不放入公共目录。离场后仍可查看本人卡片和双联；删除自己的双联不影响对方副本，也不撤销已接受交换的照片读取依据。匿名身份没有账号找回；用户填写的活动和共同歌曲不代表到场认证或音频授权。

首次保存后，按当前房间提供邀请朋友、查看同场卡片或主动展示，并保留下载与去收藏的入口；保存私卡不会自动公开。回到已离开的场次需用户主动加入。

房间使用卡片工作区，记录按个人收藏浏览；外观选择保留简短选项。页面采用 OverlayScrollbars 2.16.0 的自动隐藏 6px 浮动条，弹窗使用原生细滚动条。私藏／展示、双方同意、作品来源与 AI 示例图标记保留。

0.9 已完成本机构建，以及本人主页、跨场次收藏、HF 带歌建场、私藏保存和离场回访的关键实操；具体范围及打包、CI、同步状态见[项目状态](../docs/PROJECT_STATUS.md)。0.8 的全屏小院与运行包、0.7 的常驻场景与数据、0.6 的工作台与渲染管线、0.5.1 的界面精简、0.5.0 的主题与 PNG，以及 0.4.0 的独立身份交换、上传和导出，均保留为历史证据。
