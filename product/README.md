## 当前应用与历史参考

前端在 [`web/`](../web/)，服务在 [`server/`](../server/)。本轮主要收益与边界：

- **沿着作品认识艺人**：11 位艺人、10 首作品、10 条有来源的共同演唱关系，提供官方 MV 外链；不内置音频、不宣传完整曲库。虚构示例独立保留并兼容旧记录，真实艺人不绑定虚构活动。
- **交换自己的现场视角**：自建活动、6 位邀请码与二维码、独立匿名会话；上传压缩照片并标记舞台 / 人海 / 同伴 / 细节，默认私藏，可主动展示。对方接受指定两卡的交换后，双方各留一份当时的快照。已实际下载自己的单卡和双方双联 PNG。
- **保留可离线体验的情景演示**：同一浏览器切换两个示例角色，新交换接受后自动为双方保存；自己的卡可单独收藏。旧版已接受但未保存的交换可手动保存，相同两卡版本打开已有双联。记录仅在本机，单 HTML 可用于兼容的静态入口，不提供共享后端。

真实房间需要同源 **Node.js 24 + 持久化 SQLite** 服务，可用 Docker 部署。照片存于 SQLite BLOB，通过身份和共享关系授权读取，不放入公共图片目录。删除本人记录不会删除对方副本，也不撤销已接受交换的照片读取依据。匿名身份没有账号找回；用户填写的活动和共同歌曲不代表到场认证或音频授权。

0.4.0 已通过生产构建，单 HTML 为 **588,715 B**；重启服务执行增列迁移后，旧匿名身份和房间列表仍可读回。两个独立浏览器来源完成自建场次、真实文件选择器上传压缩、私藏 / 展示、两卡申请、接收方同意、双方记录与 PNG 下载；使用的是项目 AI 生成演示图，不是真实观众试用。真实 Map 的周杰伦 → 张惠妹与来源面板已操作，旧虚构路线保持。桌面关键画面与 390px 模拟视口的编辑 / 票根已查看，详见[项目状态](../docs/PROJECT_STATUS.md)，不扩大为实体手机或全路径验收。
