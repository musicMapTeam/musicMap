## 当前应用与历史参考

前端在 [`web/`](../web/)，服务在 [`server/`](../server/)。保留两种明确分开的体验：

- **本地情景演示**：同一浏览器切换两个示例角色，制作现场卡、申请与回应，接受后手动保存双联记忆；记录在本机。Vite 构建的单个 HTML 可用于 WorkBuddy 等兼容的静态发布入口，实际发布尚未完成。
- **真实联网房间**：独立匿名身份、6 位邀请码、房内展示与撤下、指定两卡快照交换、接收者同意、双方记录自动保存、票根 PNG 导出。共享数据由同源 Node.js 24 服务和持久化 SQLite 提供，可用 Docker 部署；仅发送预置图片引用，不上传个人照片。

0.2.0 构建已通过；两个独立浏览器存储会话走通申请、接收者接受、同步和刷新读回记录，完成必要权限检查，并下载查看 PNG 票根。已查看修复后的 390×844 票根画面；尚无实体双手机、服务重启、线上部署或外网验收。真实音频、真实合作数据、账号找回与照片云存储尚未接入。运行方式见[根 README](../README.md)，检查证据见[项目状态](../docs/PROJECT_STATUS.md)。
