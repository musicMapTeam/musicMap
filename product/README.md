1. **体验原型**：下载本目录后，用浏览器打开 [prototype/index.html](prototype/index.html)。保持同目录的 CSS、JS 文件完整。GitHub 文件预览页只能看源代码，不能直接运行 HTML。
2. **看完整流程**：[用户流程图](docs/02-user-flows.md)，或直接查看 [可视化流程总览](assets/user-flows.svg)。
3. **交给开发**：从 [开发交接说明](docs/06-handoff.md) 开始，对照 PRD 和原型交互说明。

## 一条可体验的路线

选择「林间」→ 点击中心展开代表作 → 模拟试听并留下《晚风来信》→ 收起 → 点「乔屿」→ 点「白川」→ 返回上一位 → 点「陆遥」→ 结束探索。回顾可查看歌曲及真实分支，再从“我的发现”重新打开。

挑战可选「林间」到「南枝」，沿「林间 → 陆遥 → 南枝」完成 2 步挑战；也可绕路，不要求最短。选择「孤岛来客」作为合作挑战终点，可验证不可达反馈。

## 交付边界

- 虚构艺人、歌曲、关系与字形头像只服务于交互说明，不是华语音乐数据库或真实合作证明。
- 试听按钮明确显示“模拟试听 · 无音频”。它满足可点击原型要求，不能替代正式 Demo 的真实试听验收。
- 保存发生在当前浏览器本地；不同浏览器、地址或设备不共享记录。正式部署后还需在真实手机上验收。
- 视觉为本次制作的提案，可在此基础上调整。业务规则以 PRD 为准；不因原型使用静态代码而限定搭子的技术框架。
- 项目上传与原型网页部署是两件事。只有部署后可直接访问的网页链接，才适合作为浏览器 Demo 链接；最终参赛版还要接入核验过的数据与音频。

原型与文档不包含账号密码、令牌、队伍成员个人资料、第三方音乐文件或真人照片。
