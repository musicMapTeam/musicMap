## 当前应用与历史参考

前端在 [`web/`](../web/)，服务在 [`server/`](../server/)。顶部品牌与一套空间导航连接小院、唱片店、照片墙和收藏。首页首屏写「同一刻，另一面。」、「用另一位观众的视角，补完整你记住的那一晚。」与交换三步（回访用户不显示三步）。首页的「记录我的现场」和「邀请朋友」进入真实流程，有卡后显示本人记忆；没有卡时的预置图注明示例。「体验示例」单独进入本地双角色。首页使用全屏小院，保留近期私人卡与邀请码入口；没有 hash 的访问直接打开首页。

- **沿着作品认识艺人**：唱片店默认一局寻声，例如「费玉清 → 邓紫棋，隔着几首歌？」。唱片背面朝上；在所在歌手的手牌中翻开合作，认出合唱者，再明确前往。提示分三级：还隔几首、往哪翻、揭晓。抵达后整桌翻开，给出连线歌单；答案在翻开、提示或揭晓前不出现。完整精选网（12 位艺人、13 份合作录音、13 条共唱边、2 个独立回路）收在「完整图鉴」：选唱片只查看，点线打开作品、署名和来源，「和 TA 隔几首？」另开一局。缩放、拖动与适配全图沿用稳定布局。独立开放曲库提供 120 首共同署名作品；没有试听，QQ 音乐同版本直达尚未核实。虚构示例独立保留，真实艺人不绑定虚构活动。
- **留下音乐，回看自己的现场**：「我的记录」分为我的现场、音乐收藏、探索路线和示例。真实卡片与双联跨场次集中展示；音乐单独存于本机，不依赖探索路线。作品可「带到现场」，仅预填新场次的可编辑歌名。
- **交换自己的现场视角**：自建活动、6 位邀请码与二维码、独立匿名会话；上传压缩照片并标记舞台 / 人海 / 同伴 / 细节，默认私藏，可主动展示。对方接受指定两卡的交换后，双方各留一份当时的快照，并在全屏夜场仪式页看到双联：首次首映，之后回看。主按钮「保存双联图片」生成 1600×1800 夜场票根。0.4 历史实操已下载自己的单卡和双方双联 PNG。
- **保留可离线体验的情景演示**：同一浏览器切换两个示例角色，新交换接受后自动为双方保存；自己的卡可单独收藏。旧版已接受但未保存的交换可手动保存，相同两卡版本打开已有双联。记录仅在本机，单 HTML 可用于兼容的静态入口，不提供共享后端。
- **在樱下放映 · 夜场里走动**：唯一樱花画风贯穿页面、单卡和双联 PNG，0.15 起为夜场：夜空靛紫、串灯琥珀、暖纸、樱粉与鼠尾草绿，月光投影，唱片桌由桌灯照亮。唱片纸桌、照片墙、工作桌、店内收藏和近景共用一个 Three 场景，手机独立机位，镜头与抬卡可打断；票签、照片托盘、工作纸、纪念册与封套内页共用暖纸、细墨线和索引。Three 0.186.1、Sakura Crossing MIT 管线与 GSAP 3.15.0 / Flip 保持；已授权照片才进入模型贴图，WebGL 不可用时保留同一布局的二维全网。见[视觉规范](../docs/VISUAL_THEMES.md)。

真实房间与个人现场收藏需要同源 **Node.js 24 + 持久化 SQLite** 服务，可用 Docker 部署。照片通过身份和共享关系授权读取，不放入公共目录。离场后仍可查看本人卡片和双联；删除自己的双联不影响对方副本，也不撤销已接受交换的照片读取依据。匿名身份没有账号找回；用户填写的活动和共同歌曲不代表到场认证或音频授权。

邀请朋友时，有当前房间直接展示邀请码；没有房间先留昵称、创建场次，再邀请。两步制卡在当前页面关闭再开保留草稿，修改后显示“草稿未保存”；保存成功或换房清理，刷新或切页不承诺恢复。首次保存按房间提供邀请、查看或展示，私卡不会自动公开。双联空态可回已有现场，离场后重入仍由用户主动确认；身份失效提供重新入场，新身份无法带回旧记录。

房间使用场次票签与照片托盘，本人卡、同场卡片和共同记忆按需展开；待回应申请保持显式，轮询保留目录展开状态。记录收进纪念册，换房和离开仍在“本场”菜单。场景按纸件占位重新构图，详情与表单使用窄纸面弹窗；手机弹窗暂时收起底部导航，短屏表单可滚动到保存。页面采用 OverlayScrollbars 2.16.0 的自动隐藏 6px 浮动条，弹窗使用原生细滚动条。私藏／展示、双方同意、作品来源与 AI 示例图标记保留。

0.15 构建、操作画面、运行包和 PR / 合并结果按[项目状态](../docs/PROJECT_STATUS.md)记实。本页不预先声明完成；真机双指、实体手机、读屏软件与正常硬件下的动画时长均未验证。0.14 的纸件占位构图、0.13 的完整关系网、0.12 的场景唱片桌、0.11 的邀请与草稿、0.10 的两步制卡和 PNG 预览，以及更早的场景、交换、上传和导出检查，均保留原版本范围。
