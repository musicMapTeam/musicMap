# 原型核验记录（历史：Map v0.2）

本次定稿仅补充此版本说明并修复文档链接，下方历史结果不变；它不覆盖新版 Space 社交。

日期：2026-09-26。对象：本交付包的静态可点击原型。测试环境：Windows 上的 Microsoft Edge 153.0.4234.32（Chromium 引擎，无界面自动化），含手机与桌面视口模拟。

## 已执行的自动检查

以下 18 项检查通过，执行明细见 [results.json](results.json)，脚本见 [verify.cjs](verify.cjs)。

1. 首页示例、搜索无结果反馈。
2. 拖动产生视角变化，不改变中心或路线。
3. 中心展开收起、缺试听按钮、单曲模拟状态。
4. 合作依据与连接作品可留下。
5. 清单移除、撤销、原顺序恢复。
6. 连续移动、回退与实际分支记录。
7. 模式切换不计移动、风格依据与返回状态。
8. 同一探索结束不重复建记录、刷新恢复、不自动播放。
9. 挑战起终点相同与不可达校验。
10. 挑战加步、撤销、真实回访、重置取消与确认。
11. 成功结果有效路径、独立歌曲清单、刷新后仍显示结果。
12. 返回原漫游，挑战歌曲不混入。
13. 未完成挑战退出、历史继续、成功后再次挑战。
14. 删除确认与只删除目标记录。
15. 首页在 360 / 390 / 430 / 1280 像素宽度无横向溢出。
16. 无合作邻居、空歌曲清单和仅起点结束。
17. 模拟本地保存失败，显示反馈且当前操作可继续。
18. 测试过程中未发生未捕获的页面异常。

测试中修正了自动化定位到已关闭面板内同名按钮的问题；最终执行只点击可见控件。原型实现也检查了页面切换时的抽屉清理、面板内撤销提示和完成后刷新结果等状态。

另完成 1 项专项验证：刷新挑战设置页后再开局、完成并返回，仍恢复进入挑战前的原漫游。该处已修正会话关联的初始化，结果见 [refresh-check.json](refresh-check.json)。总计为 18 项主检查和 1 项专项检查，不是正式产品全部用例的通过数量。

## 如何复跑

在装有 Node 与 Playwright 的开发环境执行 `node verification/verify.cjs`。默认使用 Playwright 的 Chromium；如需现有浏览器，可通过 `CHROMIUM_PATH` 指定可执行文件，通过 `PLAYWRIGHT_MODULE` 指定已安装的 Playwright 模块位置。路径不写入原型代码，也不需要终端用户安装依赖。

脚本会使用新的隔离浏览器上下文并生成本目录的结果文件与 assets 下的截图；不会修改开发者正常浏览器的历史或本地记录。
