# 原型设计与交互说明

版本：2026-09-26。产品规则以 [PRD](01-PRD.md) 为准。本文件把规则落实到页面与控件，视觉为本次交付提案。

## 1. 原型入口与目的

打开 [prototype/index.html](../prototype/index.html)。使用静态 HTML、CSS、JavaScript，无在线字体、图片库、播放器或接口依赖。直接打开可体验；开发验收和分享建议通过固定网页地址访问。

目的：验证页面之间能否顺利走通、空间交互是否易懂、清单是否有用、挑战规则是否清楚。虚构数据用于说明，不对真人关系做任何声明。

## 2. 页面与面板清单

| ID | 页面 / 面板 | 信息层级 | 主要操作 / 去向 |
|---|---|---|---|
| P01 | 起点搜索 | 产品定位 → 搜索 → 已收录艺人 | 选择起点进入 P02；进入 P08、P09 |
| P02 | 漫游地图 | 当前模式 → 球面关系网 → 返回导航 → 本次发现 | 邻居成为中心；中心打开 P03；关系依据 P04；清单 P05；结束 P06 |
| P03 | 代表作抽屉 | 艺人名 → 3 首示例作品 → 试听与留下 | 再点中心或关闭收起；每首单独留下 |
| P04 | 关系依据面板 | 当前艺人与邻居 → 合作作品或风格理由 | 查看依据；合作作品可试听或留下；关闭回地图 |
| P05 | 本次发现面板 | 已留下歌曲 → 可展开路线 → 可展开途经艺人 | 单曲试听、移除与撤销；继续本次探索 |
| P06 | 结束回顾 | 日期与起点 → 艺人与歌曲数 → 歌曲 → 路线与艺人 | 继续本次、从某艺人再出发、开始新探索 |
| P07 | 挑战地图 | 目标艺人和当前步数 → 合作网络 → 返回与发现 | 只沿合作移动；终点进入 P10；中途可返回漫游 |
| P08 | 我的发现 | 按更新时间排序的漫游与挑战记录 | 回顾、继续、确认删除 |
| P09 | 挑战设置 | 玩法说明 → 起点 → 终点 → 开始 | 校验相同与不可达；有效时进入 P07 |
| P10 | 挑战结果 | X 步到达 → 起终点 → 歌曲 → 最终路线与合作作品 | 再次挑战；返回原漫游；回看记录 |

P03 是可关闭的非模态抽屉，中心头像仍可操作；P04—P06 和 P10 使用可滚动面板，关闭后回到原上下文。关闭挑战成功面板回首页，已保存结果可从“我的发现”查看。

## 3. 空间网与返回

- 中心使用较大头像、细外环和“点击听代表作”提示；邻居使用较小头像与姓名。首字占位不表示正式版只允许首字头像。
- 拖动改变球面投影的水平旋转和垂直倾斜，中心保持不变。连线跟随邻居位置，远近由大小与透明度辅助表达。
- 拖动超过 8 像素判定为拖动，不再触发本次点击；这是原型参数，可根据真机体验微调。
- 点击邻居后以约 450 毫秒连续移动到中心，动画期间不接受第二次移动，避免中心与内容错配。系统减少动态效果时直接完成状态切换。
- 图下提供可点击的完整邻居列表，保证重叠或背部位置仍可访问。列表与球面使用同一批合法邻居。
- 合作线为实线、风格线为虚线，同时显示文字模式和依据；不只依赖颜色区分。
- 上一位：恢复上一节点当时模式与视角；回起点：恢复初始节点、清空当前导航路径。已走过事件与留下歌曲保留。
- 挑战回起点先确认；位于起点时两种返回按钮禁用。直接从邻居走回旧艺人仍算新移动。

## 4. 清单交互

“本次发现 · N 首”的 N 为去重后主动留下的歌曲数量。打开、关闭、看路线都不产生艺人移动。

结束回顾默认展开歌曲，路线和途经艺人折叠。歌曲为空时明确显示“这次还没有留下歌曲”，保留继续探索入口，不填充推荐歌。合作作品自动是路线依据，只有主动点击留下才进入清单。

再次点击“已留下”移除，短提示中提供撤销；撤销恢复原位置，重新主动留下放到末尾。原型展示首次收录来源；多个发现位置的聚合留待正式数据接入时扩展。

漫游回顾保留快捷返回的文字分隔和后续分支；挑战结果只显示最终有效路线。历史记录按会话保存，不把所有旅程混为一张清单。

## 5. 试听状态

| 状态 | 原型行为 | 正式实现要求 |
|---|---|---|
| 未播放 | 按钮为播放符号 | 用户主动触发真实音频 |
| 进行中 | 显示“正在模拟试听 · 无音频”，8 秒后结束 | 播放实际片段，进度与音频一致 |
| 已暂停 | 再点暂停、换中心、关抽屉、开面板、页面隐藏时停止模拟状态 | 对应暂停 / 停止真实音频 |
| 资源缺失 | “暂无试听”且按钮禁用；仍可留下文字信息 | 同原型；资源失败也需明确说明 |

全局同时只有一个试听状态。刷新不自动播放。原型没有接入真实音乐，也没有伪造音频进度条。

## 6. 视觉与适配提案

| 项目 | 本次取值 / 原则 |
|---|---|
| 背景 | 暖白 `#F5F2EB`，让关系网成为视觉中心 |
| 主文字 / 主按钮 | 深紫 `#30283E` |
| 强调 | 珊瑚色 `#AE4E39`，用于出发与留下相关提示 |
| 辅助色 | 紫灰 `#66567C`；线条 `#DED9D4` |
| 字体 | 系统中文无衬线字体；头像首字为衬线风格；不依赖付费字体 |
| 间距 | 以 4 / 8 像素为基础，正文区手机左右约 20 像素 |
| 形状 | 头像为圆形；按钮和卡片适度圆角；不画具象地球陆地 |
| 点击区域 | 主要操作约 44—48 像素高；表单有可见标签 |
| 手机 | 以 390 像素宽为主要参考，检查 360 / 390 / 430 像素；长内容纵向滚动 |
| 桌面 | 最大内容宽度约 1100 像素；地图与邻居列表分列 |
| 可访问性 | 可见键盘焦点、按钮语义、模态面板与 Escape 关闭、减少动态效果、图外邻居列表 |

原型截图位于 `assets/`，以实际运行界面为准。正式版真机手感、低性能设备和读屏体验尚需验证。

## 7. 异常样例和实现差异

| 需要体验的情形 | 原型触发方式 |
|---|---|
| 搜索无结果 | 输入“周杰伦”或任意未收录名字，提示范围；不会把真人拼入虚构网络 |
| 无试听 | 林间的第 3 首示例作品；孤岛来客的全部作品 |
| 无合作关系 | 选择孤岛来客作为漫游起点 |
| 挑战不可达 | 合作挑战选孤岛来客为一端、其他人为另一端 |
| 起终点相同 | 两个选择框选同一人 |
| 空清单 | 不留下任何歌，直接结束 |
| 分支回顾 | 林间 → 乔屿 → 白川；返回乔屿；再到陆遥 |
| 歌曲版本、同名艺人 | 正式字段已规定；当前小型样例未专门加入同名 / 多录音样本 |
| 网络或服务器更新 | 原型无服务器，不模拟；正式验收见清单 |

本原型不会开发个人分享卡片、账号、平台歌单、外跳或艺人详情页。正式版上线前须替换虚构图谱、补齐真实试听、验证素材使用与移动端表现，并完成产品验收。原型通过不等于正式参赛作品通过。
