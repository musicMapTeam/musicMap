## 4. 创作思路（100—300 字）怎么写

正文放在[参赛材料](../../docs/competition/README.md)。写作要求：

- **基础。** 以产品负责人的工作稿（07 §1）为底：“面向关注艺人、愿意探索的年轻乐迷，回应‘喜欢熟悉的歌手，却不知道如何发现相关新声音’的需求”。
- **不写没有的功能。** 工作稿里的“可拖动、可旋转”“风格联系”“试听代表作”当前都没有实现，不能写成已可用。
- **写实际做法。** 沿真实合唱录音漫游并留下歌；寻声只给起点和终点，翻开才认出下一位；回顾与发现卡片；出题给朋友不剧透；每条连线附官方来源。
- **分开已做与计划。** 按 FAQ Q4，把“已实现的部分”与“大赛期间计划深化 / 新增的部分”分开写。例如计划中的真机与试用结论，不能写成已完成；QQ 同版本入口按提交时的实际状态写。
- **不写成首创。** 没有做过检索，不宣称任何单项机制是首创。

以下是计划路线，不是已完成的录制。全片须是实际页面操作，配语音或字幕，总长 ≤3 分钟。建议用干净浏览器配置，不带扩展和账号信息。

| 时间 | 实际操作 | 讲解要点 |
| --- | --- | --- |
| 0:00–0:12 | 小院首页：「从喜欢，走向未知。」与三步 | 喜欢一位歌手，却不知道下一首去哪找 |
| 0:12–0:50 | 搜「周杰伦」出发 → 点张惠妹（沿《不该》）→ 点林忆莲（沿《双影》），留下 →「返回上一位」→ 点萧敬腾（沿《一眼瞬间》），留下 | 每条连线都是一首两人共同演唱、有官方来源的录音 |
| 同段内（可选） | 在作品旁打开 QQ 音乐同版本页 | 只有界面已接入、实测可打开时才录；页面要求登录或 VIP 就照实呈现，并说明这是离开本应用 |
| 0:50–1:15 | 「结束探索」→ 回顾：概览、留下的歌与来源、我走过的路（显示“返回张惠妹，换个方向”）、途经艺人与「从 TA 再出发」→ 保存发现卡片，看预览 | 回退不会抹掉走过的分支，留下的歌都在 |
| 1:15–2:05 | 寻声「费玉清 → 邓紫棋」：翻开《千里之外》认出周杰伦 → 前往；手牌有 10 张 → 提示①“还隔 2 首，面前 1 首会更近” → 翻开《稻香 / Stay With You》认出林俊杰 → 前往，盖「近」章 → 翻开《手心的蔷薇》“是邓紫棋！” → 抵达，整桌翻开 → 连线歌单 | 答案要自己翻出来；“最短”只指本专题 |
| 2:05–2:35 | 「出题给朋友」→ 复制链接（有系统分享面板时先弹出面板，选“拷贝”；否则直接复制）→ 另一个干净浏览器打开 → 「朋友出的题」→ 回原浏览器「保存战绩卡」，看预览 | 只发题目，不带答案和路线；二维码扫开是同一道题 |
| 2:35–2:50 | 「我的发现」：探索记录与留下的歌 | 记录只存在自己的浏览器 |

录制与剪辑规则：

- 中间操作可以剪短，但不伪造结果。
- 不加伪光标或伪点击，不用截图或改存储来冒充界面操作。
- 定格画面标「画面定格 · 供阅读」。
- `delivery/recording-source/render.mjs` 与 `edit-plan.json` 的 FFmpeg + ASS 字幕流程可以复用。它原本在 Windows 上使用 Microsoft YaHei 字体，换到本机需要调整字体。

## 8. 音频、素材与 AI

- **音频。**
  - 应用内不播放、不下载、不嵌入音频。
  - QQ 同版本链接只打开 QQ 音乐自己的页面，登录、VIP 与地区限制由对方决定。
  - FAQ Q11 的赛事歌单限定评审演示、不得对外上线，本项目没有使用。
- **数据。**
  - 关系网是人工核实的 37 份录音，来源见[扩网记录](../../references/research/2026-09-28/network-expansion.md)。
  - 开放曲库是固定版本 HF 元数据中的 126 首华语共同署名作品，只含事实性署名，不含音频或歌词。
  - 完整 CSV 只存本地，不随网页分发。
- **AI。**
  - 按实际使用说明 AI 工具在方案、界面与代码上的作用，以及团队如何筛选、修改与验证。本仓库 0.16 的提交带有 Claude 协作署名。
  - 产品本身没有 AI 推理：寻声、提示与“本专题最短”都是普通图搜索，不写成音乐智能。
