## 3. 设备、资源和内容验收

- [ ] 手机竖屏主要控件可点，页面无横向溢出；长路线、长标题及大量邻居仍可访问。
- [ ] 至少在目标 Android 浏览器与 iPhone Safari 实机验证；模拟尺寸截图不能替代真机性能和音频测试。
- [ ] 减少动态效果时仍能探索；键盘可到达主要按钮；面板焦点和关闭操作合理。
- [ ] 真实艺人与作品引用不缺失，素材人物匹配，关系有已核验依据。
- [ ] 头像失败时用占位，封面失败不影响主要操作；音频失败不伪装成功。
- [ ] 素材来源与允许使用方式已登记；原型虚构内容不会混入正式真实图谱。
- [ ] 不存在 QQ 音乐账号、外跳、艺人主页、平台歌单创建等已移除的操作入口。
- [ ] 免费部署地址可直接访问，不依赖开发电脑开机；在重新打开或无缓存场景验证加载。

## 5. 简短用户试用

让目标用户独立做三件事：从喜欢的艺人出发找到另一位、留下并再次找到一首歌、自选起终点完成一次挑战。过程中不先教按钮位置。

记录：能否独立完成、哪里犹豫或误点、是否理解两种关系、是否愿意继续探索。报告真实人数和观察，不把样例演示当真实用户研究，不用一次点击推断长期留存。
