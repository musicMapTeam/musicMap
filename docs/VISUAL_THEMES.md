# 樱下放映 · 视觉规范

2026-09-27 · MVP **0.11.0** / 产品文档 **2.2**。本文沿用原文件路径，记录当前唯一的樱花艺术方向；完成证据见[项目状态](PROJECT_STATUS.md)，业务规则见[产品方案](../product/docs/01-product-plan.md)。

## 艺术方向

同一个三渲二音乐小院，连接现场照片、唱片与共同纪念。暖白纸面、樱粉、鼠尾草绿和彩色阴影构成主色；清楚的中文、作者署名和原始照片占据操作层。丰富度来自雨篷、印刷唱片、樱树、道具、朋友视角与个人记忆。

构图变化度 / 动态强度 / 视觉密度采用 **(7, 4, 3)**，范围 1–10，只表达设计取舍，不是质量评分或设备性能指标。

| 部位 | 当前表达 |
| --- | --- |
| 首页 | 全屏小院加个人纸卡；最近的本人卡、记录和邀请直接可达，邀请码与示例是次级入口 |
| 外壳 | 顶部品牌加一套空间导航，取消重复入口和外观选择；没有 hash 时固定进入首页 |
| 探索 | 彩色唱片节点、细关系线、短作品浮卡；唱片架按需展开，保留来源与收藏动作 |
| 现场 | 照片工作区、待回应申请；换房和离开放进“本场”菜单，正常同步时间与卡片版本号退出常驻画面 |
| 制卡 | 选照片、留一句两步；更多细节折叠，可见范围与保存动作清楚；同页重开继续未保存草稿 |
| 收藏 | 本人现场、音乐、路线和示例分别浏览；双联空态可回已有现场，身份失效提供重新入场 |
| 结果 | 两位作者的照片和文字组成双联，展示真实 PNG 成品，再下载或主动分享 |

说明放在用户需要决定的位置。保留私藏／展示、指定两卡、双方同意、作品来源、示例标记与实际错误，不用段落解释可见的按钮。长内容正常滚动，不裁掉表单或保存操作。页面沿用 OverlayScrollbars 2.16.0 自动隐藏细浮动条，弹窗保留原生滚动。

## 空间与动作

`#sakura-world` 保留同一 Three 场景，导航与实物点击复用相同操作。手机独立机位，HTML 层承担表单、署名、同意与错误反馈。

| 机位 | 空间位置 | 操作 |
| --- | --- | --- |
| `home` | 小院、开放店面与树下舞台 | 本人卡进入收藏，工作桌记录现场，独立示例入口 |
| `explore` | 唱片店与唱片台 | 合作作品、制作署名、曲库、收藏与带歌名建场 |
| `live` | 照片墙 | 可见现场卡、申请与回应 |
| `editor` | 工作桌近景 | 两步制卡，决定私藏或展示后保存 |
| `records` | 店内收藏架 | 私人卡片、双联、音乐与路线 |
| `photo` | 选中照片抬起 | 预览并继续编辑、申请或打开双联 |

GSAP 3.15.0 驱动镜头和抬卡；连续选择从当前位置接续，中断旧动画。关闭弹窗回基础机位，替换弹窗不抢镜头。减少动态时直接显示目标。唱片慢转、花瓣与猫的呼吸保持轻量，动作不自动保存、公开或同意交换。

重复静态几何由 `sakura-batch.js` 按材质、阴影和操作分组实例化；照片、唱片和呼吸部件保留独立变换。场景跨 hash 路由保留，销毁时释放几何、材质、纹理、后处理目标、renderer 和监听。空闲 30fps / 转场 60fps 是调度目标，不代表实体手机已达标。

## 照片与业务边界

- 真实照片保持原内容，不做动漫化、补景或换人；页面和票根只改变外框与排版，作者、文字、活动与快照不变。
- 场景最多发布 6 张当前有权读取的卡。首页可显示本人私卡，同伴仅显示已展示的卡；缺本人卡的 seed 明示示例。
- 联网贴图取既有 bearer 接口授权的 blob，不把 `photoId` 拼成公共 URL。退出、撤权或清缓存前先撤下模型贴图，再释放 blob。
- 申请、拒绝、取消和完成画面由实际状态驱动，动画不伪造结果。私藏默认、指定接收者与双方同意继续适用。
- 当前没有内置音频或已核实的 QQ 音乐直达，图形不标作真实频谱或播放器。

## 单卡与双联 PNG

页面与 PNG 统一使用樱花纸面、柔和平涂框线和清楚署名。双联取接受时的两卡快照，单卡取本人的当前卡；AI 示例图继续带标记。生成与下载不改变房间或交换状态。

原生 dialog 展示真实 PNG，图片占主体；桌面宽度不超过 460px，手机保留边距与长按保存。提供“下载图片”“关闭预览”，浏览器支持文件分享才显示“分享图片”，用户点击后触发。预览不参与全局位移动画；关闭、下一次导出或离页释放对象 URL。

## 上游来源与适配

实际复用 [Sakura Crossing](https://github.com/Kenton-GMI/sakura-crossing) 的 MIT 渲染代码，固定提交 `de01898e89c7f6ab3fad93fa802f0f5ac66fbd81`：

| 模块 | 采用范围与本地改动 |
| --- | --- |
| `toon.js` | cel 分层明暗、彩色阴影；为独立场景创建并释放材质和色阶纹理池，适配 Three 0.186.1 shader |
| `post.js` | 深度墨线、调色和 FXAA；同步投影类型与裁切参数，控制像素预算与小场景线宽 |
| `palette.js` | 采用原调色板，文件未修改 |

Three 使用 **0.186.1**；小院建筑、雨篷、唱片、樱树、程序纹理和构图由本项目编写，没有复制上游完整街区、人物、纹理原图或音频。文件哈希、修改说明与固定来源见 [SOURCE.json](../web/js/vendor/sakura/SOURCE.json)，完整许可见[第三方说明](../THIRD_PARTY_NOTICES.md)。

GSAP / Flip 使用 [Standard No Charge 许可](https://gsap.com/community/standard-license/)。界面滚动沿用 OverlayScrollbars MIT 实现，参考取舍见[界面研究](../references/research/2026-09-27/interface-restraint.md)。

`themes.js` 沿用文件名，只管理樱花场景；`themes.css` 保留纸面 token 与浅色业务样式。旧 `festival` / `zine` 运行选择和 PNG 绘制已退出，历史偏好键 `music-map-visual-theme:v1` 不再读写或监听，不主动清除业务数据。
